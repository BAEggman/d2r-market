# D2R 장터 — 종합 거래 사이트 v1

카오스큐브식 팝니다/삽니다 게시판 + 트레디아식 아이템 구조를 합친 디아블로 2 레저렉션 거래 사이트입니다. 회원가입/로그인, 매물 등록·검색·필터, 댓글 흥정, 거래완료 처리, 그리고 **거래완료 기록이 그대로 자체 시세 데이터**가 되는 구조입니다. 전부 무료 티어(GitHub Pages + Cloudflare Workers + D1)로 돌아갑니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 프론트엔드 전체 (게시판, 등록, 로그인, 상세·댓글, 내 매물) |
| `data.js` | 아이템 사전 1,324개 — 한글/약칭 자동완성에 사용 (파인더와 동일 파일) |
| `worker-market.js` | 백엔드 API (Cloudflare Worker) — 인증·매물·댓글·쪽지·신고·관리·시세 |
| `schema.sql` | D1(SQLite) 스키마 (새 설치용, v2) |
| `migrate-v2.sql` | v1으로 이미 배포한 DB를 v2로 올리는 마이그레이션 |
| `cowork-market-deploy.md` | Cowork 자동 배포 지시서 |

## 배포 (수동 기준, 약 10분 — 자동화는 cowork-market-deploy.md)

### 1. D1 데이터베이스
1. dash.cloudflare.com → **Storage & Databases → D1 → Create** → 이름 `d2r-market`.
2. 만든 DB의 **Console** 탭에 `schema.sql` 내용 전체를 붙여넣고 실행.

### 2. Worker (백엔드)
1. **Workers & Pages → Create Worker** → 이름 `d2r-market` → Deploy → **Edit code**.
2. 기본 코드를 지우고 `worker-market.js` 전체를 붙여넣고 Deploy.
3. Worker **Settings → Bindings → Add → D1 database** → 변수명 `DB`, 데이터베이스 `d2r-market` 선택 → 저장(재배포).
4. 주소(`https://d2r-market.<계정>.workers.dev`)를 브라우저로 열어 `{"ok":true,...}` 확인.

### 3. 프론트엔드 (GitHub Pages)
1. 새 공개 저장소(예: `d2r-market`)에 `index.html`, `data.js`, `README.md` 업로드.
2. Settings → Pages → `main` / root 로 활성화.
3. 사이트 접속 → 상단 배너(또는 하단 "연결 설정")에 Worker 주소 저장.
   - 모두가 설정 없이 쓰게 하려면 `index.html` 상단의 `API_BASE_DEFAULT = ""` 에 워커 주소를 직접 넣고 커밋하세요.
4. (권장) `worker-market.js` 상단 `ALLOWED_ORIGIN` 을 `"https://<계정>.github.io"` 로 바꿔 재배포 — 다른 사이트에서 내 API를 못 쓰게 잠급니다.

## 기능 요약

- **회원**: 아이디+비밀번호 (이메일 미수집 → 개인정보 최소화). 비밀번호는 PBKDF2-SHA256 10만 회 해시로만 저장, 세션 토큰 30일.
- **비밀번호 복구**: 가입 시 1회용 **복구 코드**(예: `A3F9-1C77-…`)를 발급해 화면에 한 번만 표시. 분실 시 로그인 화면 → "복구 코드로 재설정"에서 새 비밀번호 설정(모든 기존 세션 종료 + 코드 자동 회전). 로그인 상태에서는 내 매물 → 계정 관리에서 비밀번호 변경·코드 재발급 가능.
- **매물**: 팝니다/삽니다 · 아이템 자동완성(한글/영문/약칭 1,324개) · 옵션 원문 · 룬 가격/제안받기/자유 입력 · 플랫폼(PC/스위치/PS/Xbox) · 소프트/하드 · 래더/스탠 · 버전(오리지널/확장/악군) · 연락처.
- **쪽지**: 매물 상세의 "쪽지 보내기"로 1:1 대화 시작(매물 링크 자동 첨부). 상단 쪽지 메뉴에 안 읽은 개수 배지, 대화방 목록·읽음 처리 지원.
- **흥정**: 매물 댓글. 등록자는 거래완료/숨김/수정/삭제 가능.
- **신고·관리**: 매물/댓글에 신고 버튼(하루 10건 제한). 관리자는 상단 "관리" 메뉴에서 신고 목록 확인 → 매물 숨김·댓글 삭제·계정 정지/해제·처리 완료. 정지 계정은 로그인·모든 쓰기 차단.
- **시세**: 상세 페이지 "우리 장터 완료 시세" = 그 아이템의 거래완료 기록. 트레더리 검색 링크도 함께 제공.
- **보호장치**: 가입 5회/시간·로그인 20회/10분·복구 시도 5회/시간(IP당), 매물 30건/시간, 댓글 60건/시간, 쪽지 60건/시간, 신고 10건/일, 입력 길이 제한, XSS 방지(textContent 렌더링).

## 운영 노트

- **관리자 지정**: D1 콘솔에서 한 번만 실행 — `UPDATE users SET is_admin=1 WHERE username='본인아이디';` (관리자 계정은 정지 불가).
- **v1에서 업그레이드**: 이미 v1을 배포했다면 D1 콘솔에서 `migrate-v2.sql` 실행 후 Worker 코드만 새로 붙여넣으면 됩니다. 기존 회원은 복구 코드가 없는 상태이므로, 로그인 후 계정 관리에서 "새 복구 코드 발급"을 한 번 하도록 안내하세요.
- **정말 다 잃어버린 사용자**: 비밀번호+복구 코드 모두 분실 시 자동 복구는 불가. 운영자가 본인 확인 후 D1 콘솔에서 초기화해 주는 방법만 남습니다.
- Workers 무료 한도는 하루 10만 요청, D1은 500만 읽기 — 커뮤니티 규모로는 충분합니다.
